== Description
The resource content provider API contains the interfaces to implement in order to create a content provider plugin for Gravitee.io APIM. +

== Compatibility matrix

|===
| Plugin version | APIM            | Java version

| 2.x            | 4.9.x to latest | 21
| 1.x            | 4.9.x to latest | 17
|===

The *Java version* column is the bytecode level of the latest release of each line, which sets the minimum runtime able to load the artifact.

APIM pins the version it ships — 1.0.0 on every branch from 4.9 to master — and provides it through the gateway's `lib/`, so the 2.x bump is backported to the support branches rather than left to master alone.
